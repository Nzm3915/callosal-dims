# 見直しの記録（自己改善ループ）

> 三つのプロジェクト（01 マウスの脳梁、02 分離脳ワールドモデル、03 量子脳の細胞実験）を、
> **批判 → 計画 → 実行 → 検証 → 記録** の輪で繰り返し直していく。この文書はその記録で、
> 「何を疑い、何を確かめ、結論をどう変えたか」を残す。結論を変えたときは、変える前の主張も消さずに書く。

## ループの決まりごと（これまでのやり取りから）

1. どの主張にも「こうなったら間違い」と言える予測を付ける。外れたら外れたと書く。
2. 新しい結果は、論文の再現か、合成データでの確認が通ってから信じる。
3. 統計の単位はマウス。ペアやセッションを独立に数えた検定は、マウス単位でも確かめる。
4. 中央値の比のような不安定な量で「何割を説明」と言わない。合算した比と、マウスを単位にしたブートストラップの区間で言う。
5. 文献の数値は原典で確かめる。取れない原典は書誌とURLを添えて頼む。
6. 初心者が追える文章にし、式には日本語の意味を添える。

## ループ1（2026-10-29）：状態依存性の残りは「左右の往復の信号」か

**疑ったこと**：Phase 6 で「ニューロンごとの利得で状態依存性（$c_1$）の約3割」と書いた。残り7割は、Bの状態がAを経由して戻ってくる往復（B→A→B）を失った分ではないか。

**やったこと**（`phase7/phase7_loop.py`）：

- モデルに頼らない比の推定量。光の間のAの状態を、光の前の $c_B, c_A$ で回帰した係数 $\beta$ が、止めた試行でどれだけ変わるかから、往復で失われる分を予測した。
- 両半球の選択軸を結合した力学モデル。止めた試行も学習に入れ、A→Bの結合が推定できるようにした。

**結果**：

| 推定 | 値（259組） |
| --- | --- |
| $c_0$ で校正した $w$ | 0.46。ただしこれで $c_2$ を予測すると −0.20（実測 −0.05）。校正が矛盾する |
| $c_2$ で校正した $w$ | 0.10。往復による $c_1$ の予測は −0.001（実測 −0.119）。マウス単位でも0と区別できない（p = 0.56） |
| 結合した力学モデル | 推定される左右の結合は 0.023。止めたときの落ち込み（$c_0$）すら再現しない（−0.015 対 −0.167） |

**結論**：**往復の仮説は棄却**。$c_0$ で校正した版の −0.032 は上限で、その校正自体が $c_2$ と矛盾する。

**自分の誤りの訂正**：「ニューロンごとの利得で約3割」は、組ごとの雑音の多い和の**中央値**を比べた値だった。全組を合算した比で測り直すと、次のようになった（`phase7/phase7_gain_pooled.py`）。

| 予測 | 状態依存性のうち説明できる割合（マウスを単位にしたブートストラップ95%区間） |
| --- | --- |
| 各ニューロン自身の利得（$g_i^{1}$） | 0.42 [0.19, 1.39] |
| ＋回路を1周したぶんの利得（受け取る状態の信号も $g$ で縮む） | 0.77 [0.38, 2.54] |

区間が広く、**利得だけで全部を説明できる可能性を否定できない**。「残り7割」は、確かな量ではなかった。
発火率がほとんど変わらないニューロン（0.9 < $g$ < 1.1、2,597個）が運ぶ状態の比は 0.83 [0.51, 1.17] だった。回路を1周した利得の予測 0.93 とも、1（変化なし）とも区別できない。

## ループ3（2026-10-29）：量子脳の細胞実験と、原典の精読

**Li ら 2018（*Anesthesiology* 129:271–277）を精読して見つけた弱点**：

1. **1種類の同位体につき実験は1回**。20匹を一つの箱に入れて同時に測っている。統計は20匹を独立に数えているが、日・箱・ガスのボトルといった条件は同位体ごとに一つしかない。実質の反復は各1回である。
2. **キセノンだけの値は外挿**。マウスはキセノンだけで眠らせると酸素が足りなくなるので、イソフルラン0.50%（それだけで眠る濃度の78%）を足して測っている。キセノンだけの値（70% と 105%）は、残りの22%で割って求めたもので、測った差（15–16% と 22–23%）を約4.5倍に拡大している。
3. **イソフルランのわずかな狂いに極めて敏感**。下地のイソフルランが眠る濃度の78%なので、イソフルランが0.01%ずれると、必要なキセノンは約1.1ポイント変わる。報告された差（約7ポイント）は、イソフルランが日ごとに約0.06%ずれれば説明できる。赤外線のガスモニターの絶対精度は、ふつうこれより粗い。同位体ごとに別の日に測っていれば、日ごとの校正のずれがそのまま差に乗る。
4. 測定者の盲検はあり、溶けたガスの濃度もガスクロマトグラフィーで確かめている。この点は良い。

**Franks ら 1998（*Nature* 396:324）から取れる細胞の測定法**：培養した海馬ニューロンが自分自身にシナプスを作る標本（オータプス）で、キセノン80%が NMDA 受容体の電流を約60%抑える（シナプス電流の NMDA 成分は70%以上減る）。NMDA の EC50（24±2 µM）とヒル係数（1.2）は変わらない（競合しない阻害）。GABA_A 受容体はほとんど変わらない。

→ **03 の設計を変える**：(a) 行動ではなく、この細胞の測定で同位体を比べる。イソフルランの下地がなく、外挿もいらない。(b) 同じ細胞の上で同位体を順に入れ替える（細胞の中での比較）。(c) 同位体の順番は日ごと・細胞ごとに無作為にする。(d) 溶けたキセノンの濃度は、その場で測る。


## ループ2の続き（2026-10-29）：見出しの数字と B1 を疑う

| 疑い | 確かめ方 | 結果 |
| --- | --- | --- |
| A6「受信の反応の74%が一つの方向に入る」は上に偏っていないか。方向を求めた試行の半分を、そのまま評価にも使っている | 方向を推定する3分の1と、評価する二つの3分の1を分ける | **偏っていた**。偏りのない推定では1方向で 0.51、3方向で 0.63。真の値は 0.51〜0.74 の間で、見出しは「約半分〜4分の3」と書き直す。モードの比較（選択 0.048、ランプ 0.077）は、モードを別の試行で求めているので偏りがなく、そのまま |
| A7 DLAG の比較の天井（受信の部分空間 0.89）も同じ偏りを持つ | 同じ3分割で測り直す | 天井は 0.64。DLAG は 0.20 で、差は残る（p = 9×10⁻³⁵） |
| A8 B1「確信度の高い半球が勝つ」は、片方の半球だけが行動を決めていても、測定の雑音で生じないか | セッションごとに、各半球の確信度の測定の信頼性（ニューロンを半分に分けて求める）と、両半球の相関を実データから推定する。そのうえで「片方だけが決める」モデルを合わせ、同じ統計を予測させる（127セッション） | **B1 を「支持」から「未決着」に下げる**。測定の信頼性は約0.47で、雑音を除いた両半球の選択の状態の相関は 0.9 以上（56%のセッションで上限の0.95）。左右の意見の食い違いの大部分は測定の雑音である。「片方だけが決める」モデルでも「確信度の高い側が勝つ」差は出る（予測 +0.039、観測 +0.025、差は有意でない）。確信度の高い側が勝つ割合そのもの（0.68）はモデルの予測（0.62）を上回ったが、決まった側が勝つ割合（0.64 対 0.61）も同じように上回っており、モデルが意見の割れた試行全般で行動の予測しやすさを低く見積もっているだけと考えられる（図 fig_phase7 C）。公平な比較は両者の差で、そこに違いはない。**この統計では、委員会の読み出しと片方だけの決定は区別できない** |
| A9 回路モデル（B5'）を3つの乱数の平均で当てはめ直す | 当てはめに使わない5つの乱数で試す | ばらつきの版も、ばらつき＋順応の版も、下がる細胞 30%、上がる細胞 48% で、データ（42%／20%）より上がる細胞が多すぎる。**B5' は「混ざりを生むしくみとしては必要、割合は再現できない」** |

**新しく分かったこと（A8 の副産物）**：普通の試行では、左右の半球の選択の状態は、測定の雑音を除くとほぼ同じ（相関 0.9 以上）。
それでも片側を止めたときの成績の低下は6ポイントだけで、往復の信号も状態依存性をほとんど説明しない（ループ1）。
「ほぼ同じ状態を、二つの半球が別々に保てる」ことを示しており、モジュール性（Chen 2021）と合う。
