## ループの決まりごと（これまでのやり取りから）

1. どの主張にも「こうなったら間違い」と言える予測を付ける。外れたら外れたと書く。
2. 新しい結果は、論文の再現か、合成データでの確認が通ってから信じる。
3. 統計の単位はマウス。ペアやセッションを独立に数えた検定は、マウス単位でも確かめる。
4. 中央値の比のような不安定な量で「何割を説明」と言わない。合算した比と、マウスを単位にしたブートストラップの区間で言う。
5. 文献の数値は原典で確かめる。取れない原典は書誌とURLを添えて頼む。
6. 初心者が追える文章にし、式には日本語の意味を添える。

## ループ1（2026-10-29）：状態依存性の残りは「左右の往復の信号」か

**疑ったこと**：Phase 6 で「ニューロンごとの利得で状態依存性（$c_1$）の約3割」と書いた。残り7割は、Bの状態がAを経由して戻ってくる往復（B→A→B）を失った分ではないか。

**やったこと**（`phase7/phase7_loop.py`）：

- モデルに頼らない比の推定量。光の間のAの状態を、光の前の $c_B, c_A$ で回帰した係数 $\beta$ が、止めた試行でどれだけ変わるかから、往復で失われる分を予測した。
- 両半球の選択軸を結合した力学モデル。止めた試行も学習に入れ、A→Bの結合が推定できるようにした。

**結果**：

| 推定 | 値（259組） |
| --- | --- |
| $c_0$ で校正した $w$ | 0.46。ただしこれで $c_2$ を予測すると −0.20（実測 −0.05）。校正が矛盾する |
| $c_2$ で校正した $w$ | 0.10。往復による $c_1$ の予測は −0.001（実測 −0.119）。マウス単位でも0と区別できない（p = 0.56） |
| 結合した力学モデル | 推定される左右の結合は 0.023。止めたときの落ち込み（$c_0$）すら再現しない（−0.015 対 −0.167） |

**結論**：**往復の仮説は棄却**。$c_0$ で校正した版の −0.032 は上限で、その校正自体が $c_2$ と矛盾する。

**自分の誤りの訂正**：「ニューロンごとの利得で約3割」は、組ごとの雑音の多い和の**中央値**を比べた値だった。全組を合算した比で測り直すと、次のようになった（`phase7/phase7_gain_pooled.py`）。

| 予測 | 状態依存性のうち説明できる割合（マウスを単位にしたブートストラップ95%区間） |
| --- | --- |
| 各ニューロン自身の利得（$g_i^{1}$） | 0.42 [0.19, 1.39] |
| ＋回路を1周したぶんの利得（受け取る状態の信号も $g$ で縮む） | 0.77 [0.38, 2.54] |

区間が広く、**利得だけで全部を説明できる可能性を否定できない**。「残り7割」は、確かな量ではなかった。
発火率がほとんど変わらないニューロン（0.9 < $g$ < 1.1、2,597個）が運ぶ状態の比は 0.83 [0.51, 1.17] だった。回路を1周した利得の予測 0.93 とも、1（変化なし）とも区別できない。

## ループ3（2026-10-29）：量子脳の細胞実験と、原典の精読

**Li ら 2018（*Anesthesiology* 129:271–277）を精読して見つけた弱点**：

1. **1種類の同位体につき実験は1回**。20匹を一つの箱に入れて同時に測っている。統計は20匹を独立に数えているが、日・箱・ガスのボトルといった条件は同位体ごとに一つしかない。実質の反復は各1回である。
2. **キセノンだけの値は外挿**。マウスはキセノンだけで眠らせると酸素が足りなくなるので、イソフルラン0.50%（それだけで眠る濃度の78%）を足して測っている。キセノンだけの値（70% と 105%）は、残りの22%で割って求めたもので、測った差（15–16% と 22–23%）を約4.5倍に拡大している。
3. **イソフルランのわずかな狂いに極めて敏感**。下地のイソフルランが眠る濃度の78%なので、イソフルランが0.01%ずれると、必要なキセノンは約1.1ポイント変わる。報告された差（約7ポイント）は、イソフルランが日ごとに約0.06%ずれれば説明できる。赤外線のガスモニターの絶対精度は、ふつうこれより粗い。同位体ごとに別の日に測っていれば、日ごとの校正のずれがそのまま差に乗る。
4. 測定者の盲検はあり、溶けたガスの濃度もガスクロマトグラフィーで確かめている。この点は良い。

**Franks ら 1998（*Nature* 396:324）から取れる細胞の測定法**：培養した海馬ニューロンが自分自身にシナプスを作る標本（オータプス）で、キセノン80%が NMDA 受容体の電流を約60%抑える（シナプス電流の NMDA 成分は70%以上減る）。NMDA の EC50（24±2 µM）とヒル係数（1.2）は変わらない（競合しない阻害）。GABA_A 受容体はほとんど変わらない。

→ **03 の設計を変える**：(a) 行動ではなく、この細胞の測定で同位体を比べる。イソフルランの下地がなく、外挿もいらない。(b) 同じ細胞の上で同位体を順に入れ替える（細胞の中での比較）。(c) 同位体の順番は日ごと・細胞ごとに無作為にする。(d) 溶けたキセノンの濃度は、その場で測る。

## ループ3の続き（2026-10-29）：03 の計算の副テーマ

**疑ったこと**：キセノン同位体の効果を「ラジカル対機構」で説明するなら、どれだけの物理量が要るのか。

**やったこと**（`quantum/radical_pair.py`）：電子2個・キセノンの核・相手のラジカルの陽子からなる最小の模型で、一重項収率を厳密に計算した。

**自分の誤りの訂正**：最初の版は相手のラジカル自身の核スピンを入れておらず、スピン0のキセノンでは一重項と三重項がまったく混ざらないため、同位体の効果を過大に見積もった。陽子を1つ入れて計算し直した。

**結果**：効果が10%を超えるには、ラジカル対の寿命が約10 µs 以上で、キセノンと電子の超微細結合が0.5〜1 mT 以上必要。Li 2018 の ¹²⁹Xe／¹³¹Xe の効果の比（約1.2）が出るのも、この強い結合の領域だけだった。キセノンが本当にミリテスラ級の結合を持ちうるかを、密度汎関数法で見積もることが、実験の前の決定的な計算になる。

## ループ5（2026-10-29）：03 の「決定的な計算」をやる

**疑ったこと**：ループ3で「キセノンとラジカルの超微細結合がミリテスラ級になるかが決め手」と書いたが、自分の見立て（触れるだけなので小さい）は計算していない。

**やったこと**（`quantum/xe_hyperfine.py`・`xe_hyperfine_ext.py`）：キセノンの全電子を扱う密度汎関数法（PBE0）で、ラジカルの横に置いたキセノンの核の位置のスピン密度を求めた。水素原子とメチルの陽子で方法を確かめ（強めに2〜3割）、基底関数を替えても4%しか変わらないことを確かめた。

**途中で見つけた自分の誤り**：ヒドロペルオキシルの最初の計算は、不対電子が分子の面内の軌道に入った励起状態に落ちていた。孤立したラジカルの基底状態とキセノン原子を重ねた初期値から解き直し、どの軌道にスピンがあるかを毎回出力して確かめるようにした。

**結果**：スピンが一原子に集中したラジカル（メチル・ヒドロキシル）の軌道の真上では 0.7〜2.4 mT と、予想よりずっと大きい（前の見立ては誤り）。しかし生体で候補になる広がった π ラジカル（スーパーオキシド・フェノキシル）では 0.1〜0.2 mT。ラジカル対の模型に入れると、同位体の差は 10 µs の寿命でも約2%で、Li 2018 の大きさ（必要量が約1.5倍）には届かない。

**計画への反映**：03 の6節に結果を入れ、段階1bの検出力（数%の差を見る設計）がこの予測に合っていることを書いた。差が出た場合の次の計算（受容体のキセノン部位の近くのラジカル探し）も加えた。

## ループ6（2026-10-29）：01 の利得の説明を、同じニューロンの中で確かめる

**疑ったこと**：「強く下げられた細胞ほど情報を失う」は細胞どうしの比較なので、二つが別の種類の細胞だという可能性を除けない。01 の8節の最優先の問いでもあった。

**やったこと**（`phase7/phase7_rampdown.py`）：応答の窓を光の終わりの前後にずらし、同じニューロンの発火率が戻るとき、運ぶ状態の情報が予測どおりに戻るかを見た。

**結果**：光の終盤で利得が説明するのは4割弱（合算の 0.42 と一致）。発火率は光の直後の 0.1 秒でほぼ戻り、状態依存性はその 0.1 秒後に消えた。平均の落ち込みは 0.5 秒たっても半分残る（`phase7_rampdown_mean.py`）。状態依存性は「ずれた状態の尾」ではなく、利得が下がっている間だけ現れる。組ごとの変化の相関（0.21）は組の間の違いでも出るので、決め手には数えない。

**途中の訂正**：最初は「状態依存性が発火率より遅れて残る＝利得より遅い別のしくみ」と書いたが、平均の落ち込みを同じ窓で測ると、状態依存性はそれよりずっと早く消えた。0.1 秒の遅れは集団が入力を積分する時間で説明できる範囲で、別のしくみを持ち出す必要はなかった。

**計画への反映**：01 の結論5を「状態依存性は利得が下がっている間だけ現れ、その4割を単純な利得の式が説明する」に書き直し、8節の最優先の問いを「残りの6割を回路の中の利得の伝わりで埋められるか」に置き換えた。

## ループ7（2026-10-29）：02 の試作を全条件に広げ、主問い3を試作で測る

**疑ったこと**：ループ4の「相関から求めた方向はでたらめと同じ（0.02）」は、最も細いリンク（$d$ = 1）一つだけの結果だった。また、主問い3（校正）は計画に書いただけで、試作で測っていなかった。

## ループ9（2026-10-29）：03 の計算を先行研究と突き合わせ、自分の誤りを見つける

**疑ったこと**：03 で「π ラジカルでは 0.1〜0.2 mT なので、ラジカル対では Li 2018 の大きさに届かない」と書いた。同じ問いを扱った先行研究（Smith ら 2021、*Sci Rep*）と、数字を突き合わせていなかった。

**見つけた誤り（重大）**：`radical_pair.py` の電子の磁気回転比を $1.76\times10^{8}$ rad/s/T としていた。正しくは $1.76\times10^{11}$ で、すべての周波数が1000分の1になっていた。そのため、同位体の効果が出るのに必要な寿命を 1000 倍長く見積もっていた（「10 µs 以上」は誤りで、正しくは「10〜100 ns」）。Smith ら 2021 の条件（寿命 18 ns、結合 1.9 mT）を入れたところ、効果は −31% と大きく出た。この食い違いから誤りに気づいた。

**もう一つの見落とし**：スーパーオキシドは陰イオンなので、キセノンを中性の分子より強く引きつけ、近くに来る。Smith らは 3 Å 付近にエネルギーの底を見つけた。前の計算は 3.6 Å より遠くしか見ておらず、結合を小さく見積もった可能性がある。

**やり直したこと**：磁気回転比を直し、電子スピンの緩和（速さ $r$）を入れられる解き方（リウビル空間）に書き換えた。閉じた式と、緩和なしの極限で一致することを確かめた。スーパーオキシドとキセノンの結合エネルギーの曲線（分散補正つき、BSSE を補正）を計算し、その底での超微細結合を求め直している。

**やり直した結果**：スーパーオキシドの π\* 軌道がキセノンを向くときの結合は、3.4 Å で 0.76 mT、3.0 Å で 1.29 mT と大きい。前の「0.1〜0.2 mT」は、遠い距離だけを見て陰イオンの引きつけを入れなかったための過小評価だった。

**さらに見込みが外れた点**：π\* 軌道は二つあり、両方を計算すると、**エネルギーが低いのは軌道が横を向く（節の面にキセノンが来る）場合**だった（どの距離でも 1.0〜1.3 kcal/mol 低い）。結合の大きい向きは安定でない。体温の分布で重みづけすると実効的な結合は 0.36 mT で、最初に書いた 0.76 mT は二番目に安定な状態の値だった。したがって、効果が出るにはタンパク質の中で**キセノンの向きが固定されている**ことも必要になる。

**決め手の移動**：成否は「キセノンの向きの固定」と「スーパーオキシドの電子スピンの緩和の速さ」の二つに絞れた。緩和が $3\times10^{8}$/s より速ければ、細胞の実験で見える差（2ポイント）は出ない。遊離のスーパーオキシドは $10^{9}$/s より速いと見られる（Player & Hore 2019）ので、ラジカル対の説明は「キセノンの結合部位の近くでスーパーオキシドが強く固定されている」場合に限られる。これを実験前の予言として 03 の6節に表で登録した。

**さらに加えた計算**：体温での各経路のエネルギーの桁（`energy_scales.py`）。核スピンのエネルギーは $kT$ の $10^{-10}$ 倍で平衡では効かない。重さの平衡の差はキセノンで $10^{-4}$ 以下、拡散の差は約1%。リチウムは重さが17%違い、輸送体が ⁶Li を約2%速く取り込む実測がある（Poet ら 2023）ので、キセノンと同じ扱いはできない。

## ループ11（2026-10-29）：03 の候補の表を回し、自分の予言を一つ外す

**やったこと**：`quantum/screen.py` で、4種類のラジカル × 2通りの置き方 × 4種類の核（¹²⁹Xe・¹³¹Xe・⁸³Kr・³He）の超微細結合と同位体効果を計算した（19分）。

**予言 P3 が外れた**：⁸³Kr（核スピン 9/2）は ¹²⁹Xe より効果が小さいと予想したが、結合が10〜40分の1でも効果は半分以上残った。核スピンが電子に与える実効磁場は $a\sqrt{I(I+1)}$ で効き、$I$ = 9/2 では $I$ = 1/2 の 5.7 倍になるためである。自分の直感（スピン状態が多いと平均されて薄まる）が誤っていた。

**そこから出た設計の選択肢**：⁸³Kr を使う道が開ける。ただし文献を確かめると、クリプトンは麻酔としては弱く、マウスの正向反射の消失に 4.5 気圧要る（キセノンは 0.95 気圧。Dickinson & Franks 2010）。効きが弱い分、測る抑制率も同位体差も小さくなるので、単純な乗り換えにはならない。確かな利点は一つで、**同じ元素の中にスピン0の同位体（⁸⁴Kr・⁸⁶Kr）があり、質量が1〜3しか違わない**こと。キセノンでは ¹²⁹ と ¹³² で質量が3違うので、質量の交絡を外した対照が取れるのはクリプトンだけである。

**P1 は支持**：広がった π ラジカルでは、どの核でも結合は 0.06〜0.53 mT にとどまった。
