## 大きな指摘（結論を左右しうるもの）

### R1 用語：「脳梁の入力」は測っていない

**指摘**：測っているのは「Aを止めたときにBで変わるもの」であり、脳梁だけでなく、視床や脳幹を経由する経路の効果も含む。題名や結論で「脳梁が運ぶもの」と言い切るのは過大である。

**対応**：本文の 0 節に用語の定義を加えた。本文の「脳梁の入力」は「Aを止めたときに失われる、Bへの影響の総体」と定義する。それが主に脳梁を通ると考える根拠も書いた（脳梁を切ると片側の回復が消える：Li ら 2016）。7節の限界はそのまま残した。BMI の仕様としては、「止めたときに失われる影響を再現する」ことがまさに求める性質なので、この定義で結論は変わらない。

**状態**：本文を修正。

### R2 半球のラベルが循環している

**指摘**：各ニューロンの左右のラベルは、片側を止めたときの反応で決めている。その同じ光の試行で「反対側の反応」を測っているので、循環論法にならないか。NWB のメタデータで確かめられないのか。

**調べたこと**：NWB の電極の表は、座標がすべて同じ値の仮置きだった。チャンネル番号（1〜64）は二本のプローブで重複しているので、メタデータでは確かめられない。

**対応**：光を一切使わない検査を作った（`phase7_label_validation.py`）。同じプローブの近くの電極にいる細胞どうしは、局所の速いゆらぎを共有する。光のない対照試行だけで、50 ms ごとの発火数の速いゆらぎ（試行の種類の平均と、試行ごとの平均を引いた残り）の相関を、全ペアについて求めた。

| チャンネル番号の差 | 同じラベルどうし：強く相関するペアの割合（r > 0.1） | 違うラベルどうし |
| --- | --- | --- |
| 0（同じ番号） | 3.2% | 0.37% |
| 1〜2 | 1.5% | 0.58% |
| 3〜8 | 0.83% | 0.36% |
| 9 以上 | 0.47% | 0.35% |

ラベルが正しければ、同じ番号のチャンネルでもラベルが違えば別のプローブ（別の半球）にいるので、強い相関はほとんど出ないはずだ。また、チャンネルが離れるほど相関が下がる性質は、同じラベルどうしにしか現れないはずだ。結果はその通りになった。近いチャンネル（差2以内）で比べると、39匹中36匹で同じラベルのほうが高かった（マウス単位 p = 1.5×10⁻⁷）。違うラベルの近いペアにわずかに残る超過（同じラベルの超過の約7分の1）から、誤ったラベルは多く見積もっても1割に届かない程度と見られる。

**状態**：解決。本文 4.1 節に加えた。

### R3 光が反対側に漏れていないか

**指摘**：片側への光（4.4 mW）が反対側の ALM に届けば、「反対側の反応」の一部は直接の光の効果になる。

**対応**：このマウスでは、光は抑制性細胞を**活性化**する。光が漏れていれば、Bの抑制性細胞（FS）は A への光でも**上がる**はずだ。B自身の光で 2 倍以上に上がることで同定した B の FS（414個）を見ると、B自身の光では中央値 5.8 倍に上がる。それに対して A への光では中央値 0.55 倍で、逆に下がった。A への光で 2 倍以上に上がったものは 1.4%、1.5 倍以上でも 5.3% だけだった。漏れがあったとしても、効果はごく小さく、観測された反応（7割の FS が2割以上下がる）とは向きが逆である。

**状態**：解決。本文 4.1 節に加えた。

### R4 行動の変化による見かけではないか

**指摘**：片側を止めると、マウスの体の動きや覚醒が変わる。その変化が感覚の帰還などを通って反対側を動かしているだけではないか。

**対応**：二つの証拠がある。第一に、遅延期の早すぎるなめ（体の動きの粗い指標）の割合は、対照 3.7% に対して片側を止めた試行で 3.6% と変わらなかった（マウス単位 p = 0.57）。なお、早すぎるなめのあった試行はすべての解析から除いている。第二に、反対側の FS の低下は光の最初の 50 ms のうちに始まる。体の動きを経由した帰還としては速すぎる。ただし、顔の細かい動きの動画はこのデータにないので、遅れて現れる成分に動きの寄与が混ざる可能性は残る。

**状態**：部分的に解決。本文の限界に一文加えた。

### R5 「相関の方向」の比較の基準が足りない

**指摘**：相関の方向が反応の14%しか含まないとしても、B自身がふだん大きく揺れる方向（主成分）と比べないと、「相関だから外れる」のか、「反応がふだん使わない方向に入るから外れる」のかが分からない。

**対応**：Phase 2 の出力で比べた（3次元、光の間、中央値）。相関の方向 0.14、B自身の上位3主成分 0.15、Bの試行平均の信号の方向 0.17、でたらめ 0.07 だった。相関の方向は、B自身のゆらぎの方向と同程度にしか反応を含まない。したがって正確には、「反応は、Bがふだん揺れる方向（左右で共有するものも、そうでないものも）の外に入る。だから普通の活動の統計からは見えない」と言うべきである。この区別は、Phase 3（普通の試行で学んだリンクは $R^2\approx0$）と DLAG（0.20）の結果とも整合する。

**状態**：本文 5.2 節の表と読み方を修正。

### R6 多重比較

**指摘**：仮説が十数個、検定が数十ある。偶然に有意になったものを結論にしていないか。

**対応**：本文 4.4 節に統計の方針を加えた。結論に使った正の結果（受信と相関の差、$c_0$、$c_1$、モードの比較、成績の低下、個体差）は、すべてマウス単位で p < 2×10⁻⁴ である。文書全体の検定を多めに見積もって 50 個とし、ボンフェローニ補正をかけても（閾値 10⁻³）すべて残る。仮説の多くは「棄却」で終わっており、事前に書いた「こうなったら間違い」の条件で判定した。ただし事前登録はしていないので、本研究全体は探索的な研究として位置づける。

**状態**：本文を修正。

### R7 「ゲートは要らない」は差がないことの証明ではない

**指摘**：p = 0.31 は「差が見つからない」であって、「ゲートが役に立たない」ことの証明ではない。

**対応**：同等性の形で示した。2状態ゲート − 固定リンクの、再現度（雑音を引いた $R^2$）の差のマウス単位の中央値は −0.008、95%区間は −0.015〜+0.0004 だった。固定リンクの再現度 0.38 に対して、ゲートの利点は多くても 0.0004（0.1%）である。精度ゲートは −0.011（−0.017〜−0.004）で、はっきり悪かった。

**状態**：本文 5.4 節に加えた。

### R8 DLAG の前処理への依存

**指摘**：DLAG に入れる前に試行ごとの平均を引いているので、遅延期を通して続く信号が消え、DLAG に不利になっていないか。

**対応**：平均を引かずに、4セッションに1つの割合で（31セッション）当てはめ直した。平均を引かないほうが、DLAG は左右にまたがる成分を見つけにくくなり（88% → 35%）、見つかっても止めたときの反応をより少なく捉えた（0.20 → 0.13）。半球ごとの成分が試行ごとの大きな共通の構造を吸ってしまうためと考えられる。本文の前処理は DLAG に**有利**な側だった。

**状態**：解決。本文 5.3 節に加えた。

## まとめ

結論を変える指摘はなかった。言い方を正確にしたのは二点で、「脳梁の入力」の定義（R1）と、「相関の方向」の比較の基準（R5）である。新しく示したことは五つ。光を使わない検査でラベルが正しいこと（R2）、光の漏れがないこと（R3）、動きの粗い指標が変わらないこと（R4）、ゲートの利点が 0.1% 以下であること（R7）、DLAG の前処理は DLAG に有利な側だったこと（R8）。R8 も解決し、指摘はすべて閉じた。
